How to install it

Claude.ai (no terminal needed)

  1. In Claude.ai, go to Settings → Feature Previews and turn on Code Execution. Skills won't run without it, and this requires a Pro, Max, Team, or Enterprise plan.
  2. Unzip the download if your browser didn't already. SKILL.md and the resources folder need to be at the top level of the zip you upload, not nested in another folder.
  3. Go to Settings → Features → Skills, click +, choose Upload skill, and select the zip.
  4. Toggle the skill on. Describe a shoot to Claude and it triggers automatically, no slash command needed.

Claude Code

  1. Unzip the download.
  2. Copy the folder (containing SKILL.md and resources/) into ~/.claude/skills/shoot-proposal/ for every project, or <your-project>/.claude/skills/shoot-proposal/ for just one.
  3. Start a new Claude Code session. Skills are indexed at session start, so it won't show up mid-session.
  4. Describe the shoot in plain language.

Give it whatever you already have (client name, shoot type, date, deliverables, price, usage rights) and it asks for the rest, one question at a time. It never guesses on pricing, dates, or legal terms, anything you didn't give it comes back marked TBD, confirm with client instead.
